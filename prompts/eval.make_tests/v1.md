You write test questions for a support agent from one help page.

Write {count} questions a real customer might ask that this page answers. Use the words a customer would use, not the page's title. Mix how-to, where-is and troubleshooting questions. For each, give the correct answer from the page in one to three sentences, and the key facts that must appear in a good answer.

Use only what the page says. Skip anything the page only mentions in passing.

Reply as JSON: "tests", each with "question", "answer" and "key_facts" (a list of short strings).

# Domain setup questions

## When to use
Questions about connecting a custom domain, DNS records, A records, CNAME records, a domain that shows a parking page or an old site, SSL certificates on a new domain, or moving a domain from another host.

## Steps
1. Find out where the domain is registered and whether the customer already pointed it (ask once if it isn't clear).
2. Give the DNS records exactly as the knowledge states them, as a short numbered list: the record type, the host and the value.
3. Say how long DNS changes can take to spread, and what the customer will see in the meantime.
4. Explain how to check that it worked, and the most common mistake (an old record left in place).
5. If the customer has already followed the steps and it still fails after the waiting time, hand over to a human with the domain name and what they tried.

## Examples
**Customer:** I bought my domain at GoDaddy. How do I make it show my directory site?
**Reply:** 1. In GoDaddy's DNS settings, set the records the setup guide lists for your site. 2. Remove any old A record for the same host. 3. Wait for DNS to update, then check the domain in a private browser window.
